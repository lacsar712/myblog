# 项目演进历程 (Walkthrough)

## 第一阶段：问题排查与基础加固
初始状态下，前端调用首页 API 失败。通过 `curl` 和后端日志定位到 `LazyInitializationException`。随后通过在 `ArticleService` 增加 `@Transactional` 注解解决 Session 过期问题，并优化了错误日志输出。

## 第二阶段：UI 规范化与品牌清理
根据需求，全面清理了项目中带有的 Trae 痕迹。这涉及：
1. `package.json`: 移除相关包。
2. `vite.config.ts`: 移除插件注册。
3. `index.html`: 修改 `<title>` 并清理自动注入的 script 残留。
同时对导航栏边距和页脚文案进行了微调。

## 第三阶段：响应式与交互升级
针对“看不全”和“响应式”痛点：
1. 重构了文章编辑页的 Flex 布局，使其在任何屏幕高度下都能通过内部滚动展示完整内容。
2. 为管理后台设计了专用的移动端导航弹层，解决了小屏下无法切换页面的问题。
3. 封装了 `lib/feedback.ts`，将所有交互统一到 Ant Design 体系，确保确认框居中且提示框在指定时间后自动消失。

## 第四阶段：工程文档化
最后，系统性地整理了项目的架构设计、开发流程及使用说明，并将其保存在 `docs` 目录中，确保项目的可持续维护性。
