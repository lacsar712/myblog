# 用户手册

## 快速入门
访问 `http://localhost:3501` 进入博客首页。

## 前台功能
- **阅读文章**: 点击文章卡片即可进入阅读模式，支持 Markdown 渲染。
- **返回列表**: 在阅读页面点击“返回列表”按钮。

## 后台管理
点击顶部导航的“管理后台”按钮进入管理界面。

### 文章管理
- **列表查看**: 查看所有文章及其发布状态。
- **编辑/新建**: 支持 Markdown 编辑，右侧提供实时预览。
- **发布/取消发布**: 一键切换文章在首页的可见性。

### 分类与标签管理
- 提供简洁的列表页面进行创建和删除操作。

## 响应式支持
本系统完美适配手机、平板及电脑端。在移动端，后台菜单可通过左上角的“菜单”按钮呼出。
