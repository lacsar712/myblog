# 测试报告

## 测试环境
- 操作系统: macOS
- 浏览器: Chrome
- 容器化环境: Docker Desktop

## 测试用例执行情况

### 1. 接口测试
- `GET /api/articles`: 验证分页与发布状态过滤，返回 200。
- `POST /api/admin/articles`: 验证文章保存功能，返回 200。

### 2. 功能测试
- **Markdown 渲染**: 验证图片、表格、超链接在不同屏幕宽度下的显示效果，确认无截断。
- **发布流程**: 草稿保存 -> 预览 -> 正式发布 -> 首页可见。
- **管理操作**: 分类与标签的增删查改。

### 3. UI 交互测试
- **弹窗测试**: 触发删除操作，确认 Ant Design Modal 居中弹出。
- **提示测试**: 执行保存操作，确认 Toast 在 2 秒后自动消失。
- **自适应测试**: 缩放浏览器至手机尺寸，确认顶部导航切换为汉堡菜单/弹层菜单。

## 修复记录
- 修复了 JPA 懒加载导致的 `/api/articles` INTERNAL_ERROR 问题。
- 修复了前端导航栏在小屏下无法访问侧边栏功能的问题。
